控制理论部分写了卡尔曼滤波和广义动量观测。卡尔曼滤波三篇：要解决的问题、从高斯最优估计推出五大公式、设计步骤与光流加速度计的落地。广义动量观测两篇：一维刚体的推导，多自由度推广和设计要点。

嵌入式部分写了通信。MQTT 与 IPC 一篇，讲发布订阅这套模型和板子里任务之间的通信；broker、topic 与 QoS 一篇；TCP 一篇，三次握手四次挥手和自定义协议；UDP 与 socket 一篇，包括 Linux 下的 SocketCAN。

每篇对应的工程按专题分目录放在仓库里，文章末尾写了代码在哪个目录。
