## 从高斯最优估计推出互补滤波形式（标量）

### 1. 问题设定与高斯假设

待估计真值 `v`（固定未知，例如真实速度）。手头有两样东西：

**先验（预测支路）**  
由模型/另一传感器推出来的预测 `v⁻`，以及预测误差方差 `P⁻`：

```
v ~ N(v⁻, P⁻)
```

含义：我们认为真值大概率落在 `v⁻` 附近，不确定度为 `P⁻`。

**量测（测量支路）**  
传感器读数 `z` 直接测速度（`H = 1`）：

```
z | v ~ N(v, R)
```

含义：在真值给定时，`z` 围绕 `v` 抖动，方差为 `R`。

假设：

- 先验误差与量测噪声独立
- 二者均为高斯

### 2. 最优估计 = 后验均值

在高斯假设下，下面几个准则给出同一个解：

| 准则 | 含义 |
|------|------|
| MMSE | 最小化 `E[(v - v̂)²]` |
| MAP | 最大化后验密度 |
| 条件期望 | `v̂ = E[v \| z]` |

对高斯分布，后验仍是高斯，且

```
v̂ = E[v | z]
```

就是最优估计。不需要事先假设“估计一定是加权平均”——条件期望算出来是什么形式，就是什么形式。

### 3. 联合分布与条件期望

把 `v` 和 `z` 看成联合高斯。记：

```
E[v] = v⁻
Var(v) = P⁻
z = v + n,    n ~ N(0, R),    n 与先验误差独立
```

则：

```
E[z] = v⁻
Var(z) = P⁻ + R
Cov(v, z) = Cov(v, v + n) = Var(v) = P⁻
```

联合高斯的条件期望公式：

```
E[v | z] = E[v] + Cov(v, z)/Var(z) · (z - E[z])
```

代入：

```
v̂ = v⁻ + P⁻ / (P⁻ + R) · (z - v⁻)
```

令

```
K = P⁻ / (P⁻ + R)
```

则

```
v̂ = v⁻ + K · (z - v⁻)          (卡尔曼更新)
```

整理成加权平均：

```
v̂ = (1 - K) · v⁻ + K · z        (互补滤波形式)
```

### 4. 结论：互补滤波形式是推出来的

对照经典互补滤波：

```
v̂ = α · v⁻ + (1 - α) · z
```

立刻得到：

```
α = 1 - K,    量测权重 = K = P⁻ / (P⁻ + R)
```

所以：

> **在高斯假设下，最优估计（后验均值）自动长成“预测与量测的加权和”。**  
> 卡尔曼滤波 = 互补滤波，且权重 `K` 由 `P⁻`、`R` 唯一确定，不是人工调出来的。

权重性质：

| 情况 | `K` | 含义 |
|------|-----|------|
| 预测很不确定（`P⁻` 大） | `K → 1` | 几乎全信量测 |
| 量测很噪（`R` 大） | `K → 0` | 几乎全信预测 |
| 两边相当 | `K ≈ 0.5` | 接近简单平均 |

后验方差（可由条件方差公式或直接代入验证）：

```
P = Var(v | z) = P⁻ · R / (P⁻ + R) = (1 - K) · P⁻
```

比单独用预测（`P⁻`）或单独用量测（`R`）都小——这就是“融合后可信度更高”的数学表述。

### 5. 与“方差最小化”推导等价

在线性高斯情形，也可以先**假设**估计取加权形式

```
v̂ = (1-K)·v⁻ + K·z
```

再对融合误差方差

```
P(K) = (1-K)² · P⁻ + K² · R
```

求极值：

```
dP/dK = -2(1-K)·P⁻ + 2K·R = 0
⇒ K = P⁻ / (P⁻ + R)
```

结果与条件期望完全相同。  
两条路等价，是因为高斯下 MMSE 估计就是条件期望，而条件期望恰好是线性的。

推荐记忆方式：

- **形式**：互补滤波（预测与量测加权）
- **权重**：高斯条件期望 / 最小方差，得到 `K = P⁻/(P⁻+R)`
- **递推**：每时刻先更新 `P⁻`，再算 `K`，再融合

### 6. 推广到矩阵形式（多状态）

状态为向量、量测为 `z = H x + v` 时，对联合高斯做同样的条件期望运算，得到：

```
K = P⁻ · Hᵀ · (H · P⁻ · Hᵀ + R)⁻¹
x̂ = x⁻ + K · (z - H·x⁻)
```

整理：

```
x̂ = (I - K H) · x⁻ + K · z
```

这仍是互补滤波：`x⁻` 是预测支，`z` 是测量支，`K` 把新息

```
z - H·x⁻
```

按最优权重回灌到预测上。

每个采样时刻都在做：**先按模型推进预测，再按 `K` 用量测把预测拉回来**。  
预测协方差 `P⁻` 每步会涨（过程噪声 `Q` 推动），量测又把它压回去（`R` 与 `K` 决定压多少）——权重在时间上自动变化，这是固定系数的经典互补滤波做不到的。

## 从互补滤波推导出完整卡尔曼滤波（不带具体应用）

上一节说明了：**一次融合**的形式是互补滤波，权重来自高斯最优估计。  
但滤波器要能**在线跑**，还缺几块：预测从哪来、不确定度如何随时间演化、多状态时如何更新。  
下面在不绑定光流/加速度计的前提下，从互补形式出发，把缺的部分一块块补上，最终拼出五大公式。

### 第 0 步：已有什么

一次融合（标量，`H = 1`）：

```
预测：x⁻，方差 P⁻
量测：z，噪声方差 R
融合：x̂ = (1-K)·x⁻ + K·z
权重：K = P⁻ / (P⁻ + R)
后验：P = (1-K)·P⁻
```

这是“单拍”的最优互补。要变成滤波器，必须回答：

1. 下一拍的 `x⁻` 从哪来？
2. 下一拍的 `P⁻` 从哪来？
3. 状态是向量、量测不是直接测状态时怎么办？

### 第 1 步：预测从哪来 —— 状态空间（先验方程）

预测不能凭空产生，要靠**状态如何演化**的模型。

设状态按线性模型推进，控制输入 `u` 驱动：

```
x_k = F · x_{k-1} + B · u_k
```

- `F`：状态转移矩阵（系统自己怎么走）
- `B`：控制输入矩阵（外界输入怎么推状态）

于是：

```
x⁻_k = F · x̂_{k-1} + B · u_k
```

含义：**上一拍融合结果 `x̂_{k-1}` 经模型推进，得到本拍预测**。  
这就是互补滤波里“预测那一支”的来源；`u` 可以来自另一个传感器按物理关系推导，也可以只有模型。

过程噪声 `w`（协方差 `Q`）描述模型有多不准：

```
x_k = F · x_{k-1} + B · u_k + w,    w ~ N(0, Q)
```

### 第 2 步：预测不确定度如何演化 —— 先验协方差

只有点估计不够，必须同步传播“预测有多不确定”。

若上一拍后验误差协方差为 `P_{k-1}`，则：

```
P⁻_k = F · P_{k-1} · Fᵀ + Q
```

- `F P Fᵀ`：不确定度按动力学被 `F` 搬运/放大
- `+ Q`：模型本身不可靠，每步再涨一点

没有这一步，`K` 就无法随时间变化，退化成固定权重。

### 第 3 步：量测如何由状态生成 —— 观测方程

量测不一定直接等于状态，一般写成：

```
z_k = H · x_k + v,    v ~ N(0, R)
```

- `H`：观测矩阵（状态被“看”成了什么）
- `R`：量测噪声协方差

互补融合用的不是 `z` 本身，而是**新息**：

```
新息 = z_k - H · x⁻_k
```

即“量测相对预测多出来的那部分”。

### 第 4 步：把单拍互补滤波写成矩阵形式

第 0 步的标量公式，对“`z` 直接测 `x`”（`H = I`）可直接用。  
一般 `H` 时，对联合高斯做同样的条件期望运算，得到矩阵卡尔曼增益：

```
K_k = P⁻_k · Hᵀ · (H · P⁻_k · Hᵀ + R)⁻¹
```

融合：

```
x̂_k = x⁻_k + K_k · (z_k - H · x⁻_k)
     = (I - K_k H) · x⁻_k + K_k · z_k
```

仍是互补滤波：预测支 `x⁻`，测量支 `z`，新息按 `K` 回灌。

### 第 5 步：融合后不确定度也要更新 —— 后验协方差

融合后误差变小了，必须把 `P` 压回去，供下一拍用：

```
P_k = (I - K_k · H) · P⁻_k
```

（数值上也可用 Joseph 形式，更稳。）

### 第 6 步：五大公式凑齐

把上面各步按执行顺序排好，就是离散卡尔曼滤波的递推：

**预测（Predict）**

```
① x⁻_k = F · x̂_{k-1} + B · u_k
② P⁻_k = F · P_{k-1} · Fᵀ + Q
```

**更新（Update）**

```
③ K_k = P⁻_k · Hᵀ · (H · P⁻_k · Hᵀ + R)⁻¹
④ x̂_k = x⁻_k + K_k · (z_k - H · x⁻_k)
⑤ P_k = (I - K_k · H) · P⁻_k
```

对照互补滤波：

| 公式 | 在互补滤波里的角色 |
|------|--------------------|
| ①② | 预测那一支：推进点估计 + 推进不确定度 |
| ③ | 算出当前最优互补权重 |
| ④ | 预测与量测加权融合 |
| ⑤ | 融合后不确定度收缩，供下一拍预测用 |

### 缺什么就补什么（设计时的思考顺序）

实际设计滤波器时，不必先背五大公式，而是按“互补滤波缺什么”往下补：

| 已有 | 还缺 | 补出来的东西 |
|------|------|--------------|
| 要融合预测和量测 | 预测怎么来 | 状态方程 → `F`、`B` |
| 预测会不准 | 不确定度怎么涨 | 过程噪声 → `Q`，`P⁻ = FPFᵀ+Q` |
| 量测不是直接读状态 | 状态被测成了什么 | 观测方程 → `H` |
| 量测会抖 | 抖多少 | 量测噪声 → `R` |
| 要最优权重 | 权重公式 | `K = P⁻Hᵀ(HP⁻Hᵀ+R)⁻¹` |
| 融合完还要继续 | 下一拍的 `P` | 后验更新 → ⑤ |

这就是“在已知本质是互补滤波的前提下，逐渐推导设计出卡尔曼滤波”的完整路径。
