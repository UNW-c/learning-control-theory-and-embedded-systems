## 问题

系统里常有这样一类量：

- 物理上真实存在，且对控制很重要（碰撞力、接触力、环境阻力矩等）
- 传感器测不到，或测得很差（噪声大、带宽低、装不下、成本高）
- 但它和某些**可测状态**之间，通过物理定律有确定关系

目标：用可测量，把这类不可测量**在线推出来**。

本专题具体场景是：外部力 `fe`（多维时为关节外力矩 `τ_ext`）不可直接测量。  
已知/可测：驱动力 `f`、速度 `v`、质量 `m`（多维时为 `τ`、`q̇`、以及可计算的 `M(q)` 等模型项）。

一种直觉做法是对动量直接微分：

```
fe ≈ ṗ - f
```

但 `p` 由可测量构造，数值微分会放大噪声，结果不可信。  
所以不能直接走“微分求力”这条路。

广义动量观测器（Generalized Momentum Observer, GMO）的做法是：  
**找一个中间状态，建一个影子状态，用反馈把二者拉近**，从而在不微分的前提下得到外力估计。

## 核心思路

整条逻辑可以压成四步。

### 1. 找中间状态 `p`

直接从“不可测量”接到“可测量”往往接不上。  
先找一个**中间状态** `p`，它满足两条：

1. 完全由可测量构造出来（例如 `p = m·v`，`m`、`v` 可测）
2. 它的导数里，既含有可测量，也含有目标不可测量

这个 `p` 就是**广义动量**。  
对一维刚体：`p = m·v`；对机械臂：`p = M(q)·q̇`。

### 2. 写出真值关系

由物理定律，`p` 的导数与可测量、目标量之间有确定等式。  
一维牛顿第二定律给出：

```
ṗ = f + fe
```

- `f`：已知作用力（可测/可知）
- `fe`：待观测的外部力（不可测）
- `p`：广义动量，由 `v`、`m` 构造

这条式子在物理上成立，但不能直接拿来算 `fe = ṗ - f`，因为要对可测的 `p` 做数值微分。

### 3. 建影子状态 `p̂`（并解释：为什么这会变成一个控制系统）

既然不能直接微分，就引入一个**影子动量** `p̂`：

- 它由我们自己写的一阶微分方程演化出来，数值平滑、可控
- 它的结构刻意模仿真值关系：把未知的 `fe` 换成我们**可设计**的量 `r`

```
ṗ̂ = f + r
```

初值通常取 `p̂(0) = 0`。

关键在于：`p̂` **可以定义**，但它的**数值不能凭空确定**。  
我们无法事先让 `p̂`（或 `ṗ̂`）与真值 `p`（或 `ṗ`）强相关、强相等——因为如果已经能强相等，就等于已经知道了 `fe`，观测器也就不需要了。

于是采取的做法是：

1. 设定 `p̂(0) = 0`（或任意初值）
2. 设计 `r`，使得当 `t → ∞` 时，`p̂` 收敛到 `p`，从而 `r` 收敛到 `fe`

这一步已经不再是“做一次代数变换”，而是**控制系统设计**：

- 希望跟踪的目标量：真值关系里的未知部分（对应 `fe`，或等价地，希望 `ṗ̂ → ṗ`）
- 当前可测、可算的量：`p = m·v` 与我们自己积分出来的 `p̂`，从而误差 `e = p - p̂` 可测
- 进入被控对象方程、且可以人为设计的量：`r`（出现在 `ṗ̂ = f + r` 里）

也就是说：**误差可测、控制量可设计、目标是让误差趋于零**——这已经构成一个可控的闭环控制系统。

### 4. 设计控制器，把闭环写完整

现在场景变成标准的误差跟踪问题：

| 角色 | 符号 | 说明 |
|------|------|------|
| 目标量 | `fe`（最终希望 `r` 收敛到它；等价地希望 `ṗ̂ → ṗ`） | 不可测 |
| 误差 | `e = p - p̂` | 由可测量与影子状态直接算出，**不需要微分** |
| 控制量 | `r` | 人为设计，进入 `ṗ̂` 的方程 |

缺的只是一个**控制器**：建立 `r` 与误差 `e` 的函数关系。

选**比例控制器**：

```
r = k · e,    k > 0
```

选 P 而不先上 PID 的原因很直接：

- 设计最简单，只有一个增益
- 代入后误差动力学仍保持**一阶线性**，收敛性可以直接解出来

把真值关系与影子关系相减：

```
ė = ṗ - ṗ̂ = (f + fe) - (f + r) = fe - r
```

因为 `t → ∞` 时希望 `ṗ̂` 与 `ṗ` 等效，二者结构相同，所以这里得到的是

```
ė = fe - r
```

而不是别的组合。再代入 `r = k·e`：

```
ė = fe - k · e
```

这就是整条链路的核心方程。

**为什么最后要解的是 `e(t)`（从而 `r(t)`）？**

因为我们的核心诉求是拿到 **`r` 关于时间的函数**：

- `r` 在数学上最终会收敛到 `fe`，所以需要知道它是否收敛、何时收敛、收敛到什么程度
- 而 `r` 与 `e` 只差一个常数倍：`r = k·e`
- 因此求 `r(t)` 与求 `e(t)` 等价
- 当前式子里只剩 `e` 和已知量，所以把 `e` 的时间函数解出来即可

后面所有分析，都是在解 `ė = fe - k·e`，看 `e(t)`（从而 `r(t)`）的收敛性。

## 一维刚体：完整推导

### 问题设定

已知/可测：

- 质量 `m`
- 速度 `v`
- 驱动力 `f`

待观测：

- 外部力 `fe`

### 建立真值关系

牛顿定律：

```
m · a = f + fe
```

广义动量定义：

```
p = m · v          （可由 m、v 直接算出）
```

对时间求导：

```
ṗ = m · a = f + fe
```

于是：

```
ṗ = f + fe                 (1)  真值关系
```

### 影子状态与控制量

```
ṗ̂ = f + r                  (2)  观测器结构
p̂(0) = 0
```

`r` 是待设计的反馈项。

这里再明确一次场景：直接对 `p` 求导噪声很大、不可信，所以建立影子状态 `p̂`。  
我们希望 `ṗ̂` 与 `ṗ` 在性质上相同；但“强相等”一开始无法成立，因为 `ṗ̂` 是预测量，且 `p̂(0) = 0`。  
于是只能断定：在合适的 `r` 设计下，`p̂` 最终会收敛到 `p`。

为了尽可能保证结构一致，把 `ṗ̂` 写成与 `ṗ = f + fe` 同型：

```
ṗ̂ = f + r
```

其中 `r` 是人为定义的可控量。

### 误差动力学

```
e = p - p̂
ė = ṗ - ṗ̂ = fe - r        (3)
```

注意这里是 **`ė = fe - r`**，不是 `e = fe - r`。  
误差与力量纲不同，满足的是微分关系，不是代数相等。

此时场景已经明确：

- 需要跟踪的目标：`ṗ`（其未知部分对应 `fe`）
- 目前可测的受控对象：`p̂`（通过 `p` 与 `p̂` 得到误差 `e`）
- 可以人为设计的控制量：`r`

这就是一个**误差跟踪的控制系统**，还缺一个控制器。

### 比例控制器

控制器就是建立误差与控制量之间的关系，所以：

```
r = k · e                  (4)  k > 0
```

代入 (3)：

```
ė = fe - k · e             (5)  一阶线性误差方程
```

### 求 `e(t)` 的时间函数

最终目的是要得到 **`r` 关于时间的函数**，因为 `r` 在数学上等效为 `fe`，会收敛到 `fe`。  
所以需要知道：

- 是否收敛
- 何时收敛
- 收敛程度如何

又因为 `r` 与 `e` 在等式上是倍数关系：

```
r(t) = k · e(t)
```

求 `r` 的时间函数和求 `e` 的时间函数等价。  
当前式子 (5) 里只剩 `e` 和已知量，所以在全是 `e` 的表达式内求 `e(t)` 即可。

**情况 A：`fe` 为常值**

式 (5) 的解析解：

```
e(t) = fe/k + (e(0) - fe/k) · e^(-k t)
```

因此：

```
r(t) = fe + k · (e(0) - fe/k) · e^(-k t)
     = fe + (k·e(0) - fe) · e^(-k t)
```

性质：

| 项目 | 结论 |
|------|------|
| 是否收敛 | 是，`k > 0` 时指数收敛 |
| 收敛到谁 | `e → fe/k`，从而 `r → fe` |
| 时间常数 | `τ = 1/k`，`k` 越大收敛越快 |
| 初值影响 | `e(0) = p(0) - p̂(0) = p(0)`（若 `p̂(0)=0`） |

稳态时：

```
ė = 0  ⇒  fe - k·e = 0  ⇒  e = fe/k  ⇒  r = k·e = fe
```

**情况 B：`fe` 时变（慢变）**

`r` 只能**跟踪** `fe`，存在与 `1/k` 同阶的滞后。  
`k` 越大跟踪越紧，但对 `p = m·v` 的量测噪声越敏感——这是观测器带宽与噪声的经典权衡。

### 观测器最终形式（连续时间，一维）

把 (2)(4) 合并，实际实现时只积分这一个状态：

```
ṗ̂ = f + k · (m·v - p̂)
输出：fe_hat = r = k · (m·v - p̂)
```

初始化：`p̂(0) = 0`。  
全程**没有对任何量测做数值微分**——这是广义动量观测器相对“直接差分求力”的核心优势。

## 离散形式（一维）

实现时在固定采样周期 `dt` 下进行。  
原则：把连续积分换成欧拉（或其它数值积分），微分换成差分。

### 连续 → 离散对照

| 连续 | 离散 |
|------|------|
| `p = m·v` | `p_k = m·v_k` |
| `ė = fe - r` | `(e_k - e_{k-1})/dt ≈ fe_k - r_k` |
| `ṗ̂ = f + r` | `p̂_k = p̂_{k-1} + dt·(f_{k-1} + r_{k-1})` |
| `r = k·e` | `r_k = k·e_k` |

### 推荐的计算顺序（每个采样时刻）

先用**上一拍**的控制量更新影子动量，再用**本拍**量测算误差、算新的 `r`：

```text
初始化: p̂_0 = 0, r_0 = 0

每个 k = 1, 2, ...:
    # 1) 量测
    读取 m, v_k, f_k
    p_k = m * v_k

    # 2) 用上一拍 r 更新影子动量（一阶欧拉积分）
    p̂_k = p̂_{k-1} + dt * (f_{k-1} + r_{k-1})

    # 3) 误差与反馈
    e_k = p_k - p̂_k
    r_k = k * e_k

    # 4) 输出
    fe_hat_k = r_k
```

说明：

- `f_k`、`v_k` 在同一拍采样；积分步用 `f_{k-1}` 与 `r_{k-1}`，避免代数环
- 若力测量与速度测量同步且延迟可忽略，也可用 `f_k` 做本拍积分，差别是半拍延迟
- `dt` 要满足 `dt << 1/k`，否则离散化会破坏连续设计的收敛性

### 离散误差动力学（常值 `fe`，用于理解收敛）

将 `p̂` 更新与 `r = ke` 代入后，误差近似满足：

```
e_k ≈ (1 - k·dt) · e_{k-1} + dt · fe
```

稳定条件：`|1 - k·dt| < 1`，即

```
0 < k·dt < 2
```

实用上取 `k·dt ≪ 1`（例如 `k·dt < 0.1`），更接近连续时间行为。  
稳态：`e → fe/k`，`r → fe`，与连续情形一致。
