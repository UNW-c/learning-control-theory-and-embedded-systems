## 多自由度推广（n 维刚体 / 机械臂）

### 动力学与广义动量

一维跑通后，推广到机械臂。动力学方程变为矩阵形式，中间量从标量动量变成广义动量向量。

标准的刚体动力学：

```
M(q) · q̈ + C(q, q̇) · q̇ + g(q) = τ + τ_ext
```

| 符号 | 含义 |
|------|------|
| `q, q̇` | 关节位置、速度（可测） |
| `M(q)` | 惯性矩阵，对称正定 |
| `C(q, q̇)` | 科氏/离心项 |
| `g(q)` | 重力项 |
| `τ` | 驱动关节力矩（已知） |
| `τ_ext` | 待观测的外部广义力矩 |

广义动量定义为：

```
p = M(q) · q̇
```

`q`、`q̇` 可测，`M(q)` 可由模型算出，故 `p` 可在线构造。

### 真值关系（关键一步）

```
ṗ = Ṁ · q̇ + M · q̈
```

由动力学方程：

```
M · q̈ = τ + τ_ext - C · q̇ - g
```

所以：

```
ṗ = τ + τ_ext - C·q̇ - g + Ṁ·q̇
```

机械臂动力学有一条标准结构性质：对按 Christoffel 符号构造的 `C`，有

```
Ṁ(q, q̇) - 2C(q, q̇)  为斜对称矩阵
```

由此可得 `Ṁ = C + Cᵀ`（因 `M` 对称）。代入上式：

```
ṗ = τ + τ_ext - g + Cᵀ · q̇
```

即：

```
ṗ = τ - g(q) + Cᵀ(q, q̇) · q̇ + τ_ext        (6)
```

多维与一维的差别就在这里：真值关系多出了 `Cᵀ q̇` 与 `g(q)` 两项，观测器必须把它们正确扣掉。

### 多维观测器结构

模仿 (6)，把 `τ_ext` 换成可设计的 `r`：

```
ṗ̂ = τ - g(q) + Cᵀ(q, q̇) · q̇ + r            (7)
p̂(0) = 0
```

误差与反馈：

```
e = p - p̂
r = K_o · e          K_o = diag(k₁, ..., kn),  kᵢ > 0
```

误差动力学：

```
ė = τ_ext - r = τ_ext - K_o · e              (8)
```

若 `τ_ext` 为常值（或慢变），每个关节的误差分量独立地满足：

```
ėᵢ = τ_ext,i - kᵢ · eᵢ
```

于是：

```
eᵢ(t) → τ_ext,i / kᵢ
rᵢ(t) → τ_ext,i
```

输出：

```
τ_ext_hat = r = K_o · (p - p̂)
```

与一维完全同构，只是标量 `k` 变成对角增益矩阵 `K_o`。

### 离散形式（多维）

```text
初始化: p̂ = 0 ∈ Rⁿ, r = 0 ∈ Rⁿ

每个 k = 1, 2, ...:
    # 1) 量测与模型计算
    读取 q_k, q̇_k, τ_k
    p_k   = M(q_k) @ q̇_k
    g_k   = g(q_k)
    Cᵀv   = C(q_k, q̇_k).T @ q̇_k

    # 2) 用上一拍更新影子动量
    p̂_k = p̂_{k-1} + dt * (τ_{k-1} - g_{k-1} + Cᵀv_{k-1} + r_{k-1})

    # 3) 误差与反馈
    e_k = p_k - p̂_k
    r_k = K_o @ e_k          # K_o 对角

    # 4) 输出外部力矩估计
    τ_ext_hat_k = r_k
```

注意：

- 需要在线计算 `M(q)`、`g(q)`、`Cᵀ q̇`，计算量比一维大，但不需要对 `q̇` 再微分
- `C` 的构造方式必须与“`Ṁ - 2C` 斜对称”这一性质一致，否则 (6) 不成立，`τ_ext_hat` 会含未建模项
- 若只需部分方向的外部力矩，可把对应 `kᵢ` 调大/调小，或在输出端做选择

### 从关节力矩到末端力（可选）

若真正关心的是末端执行器外力 `f_ext`，且满足静力学映射：

```
τ_ext = J(q)ᵀ · f_ext
```

则在估得 `τ_ext_hat = r` 后，可用伪逆：

```
f_ext_hat = Jᵀ⁺ · r
```

前提：雅可比不满秩时伪逆不稳定，需加权/加正则，或只在任务空间可控方向上观测。

## 设计要点

### 增益 `k` 怎么选

| `k` 偏大 | `k` 偏小 |
|----------|----------|
| 收敛快、跟踪紧 | 收敛慢、滞后大 |
| 放大量测噪声（`v` 抖动直接进 `e`） | 对噪声更钝感 |
| 离散实现要求更小的 `dt` | `dt` 约束更松 |

经验起点：让连续时间常数 `τ = 1/k` 落在你关心的外力动态的 1/3 ~ 1/5 以下，并保证 `k·dt < 0.1`。

### 与“直接微分求力”的对比

| 方式 | 问题 |
|------|------|
| `fe ≈ m·(v_k - v_{k-1})/dt - f` | 微分放大噪声，不可用 |
| 广义动量观测器 | 只积分平滑的 `p̂`，用 `p - p̂` 做反馈，全程无比分 |

### 模型误差

观测器里的 `m`、`M(q)`、`C`、`g` 若不准：

- 误差动力学不再是干净的 `ė = τ_ext - K e`
- 未建模动态会被“吸进” `τ_ext_hat`，表现为偏置或伪外力
- 一维时质量标定错误会直接把 `r` 的稳态值按比例拉偏

### 和卡尔曼滤波的关系

便于对照已有专题一：

| | 广义动量观测器 | 卡尔曼滤波 |
|--|----------------|------------|
| 框架 | 确定性 Luenberger 型反馈 | 随机最优估计 |
| 增益 | 人为给定 `k` / `K_o` | 由 `Q`、`R` 协方差推出 |
| 关注点 | 外力收敛速度与噪声权衡 | 多源信息融合、协方差一致性 |
| 是否需要噪声模型 | 不强制 | 必须 |

两者可以组合：例如对 `p` 用滤波器预平滑，再进 GMO。

## 最小可运行伪代码（一维）

```python
# 连续思想的离散实现；k_gain 即文中 k
class GeneralizedMomentumObserver:
    def __init__(self, dt, k_gain, m):
        self.dt = dt
        self.k = k_gain
        self.m = m
        self.p_hat = 0.0
        self.r = 0.0

    def step(self, v, f):
        p = self.m * v
        # 用上一拍 r 积分影子动量
        self.p_hat += self.dt * (f + self.r)
        e = p - self.p_hat
        self.r = self.k * e
        return self.r          # fe_hat
```

多维时把 `m*v` 换成 `M(q)@q̇`，把 `f` 换成 `τ - g + Cᵀ@q̇`，把 `k` 换成对角 `K_o` 即可，结构不变。

约简形式（消去 `p̂`，代数等价，对应手写伪代码）：

```
r_k = r_{k-1} + k * (p_k - p_{k-1} - f*dt - r_{k-1}*dt)
```

由影子形式 `e_k - e_{k-1} = p_k - p_{k-1} - dt(f + r_{k-1})` 两边乘 `k` 得到。  
两种形式在实现里都保留，可用按钮切换对比。

## 仿真与调参

项目目录：`广义动量观测学习/`

```bash
cd 广义动量观测学习

```

界面按「学习怎么调 `k`」设计：

- 主曲线：`fe` 真值 vs `fe_hat`（蓝线应贴虚线）；红线为直接微分对照
- 滑条：`k`（对数）、速度噪声、模型质量
- 场景：阶跃 / 正弦 / 方波 / 脉冲串
- 右侧诊断面板实时给出：
  - `τ = 1/k`、`k*dt`（是否 < 0.1）
  - 滞后时间（互相关估计）、噪声差分 RMS
  - 阶跃稳定时间（约 `2τ~3τ` 量级）
  - 结论：滞后偏大→增大 `k` / 噪声偏大→减小 `k` / 模型偏差 / 离散不稳
- 按钮：影子/约简形式切换、播放、重采噪声

调 `k` 时只盯主曲线 + 诊断结论，不要只看 `e` 的大小（常值 `fe` 下 `e→fe/k`，`k` 一大 `e` 自然变小）。

## 小结

广义动量观测器可以压缩成一句话：

> 用可测动量 `p = Mv` 做参考，用结构相同的影子方程 `ṗ̂ = （已知项）+ r` 做积分，用比例反馈 `r = K(p - p̂)` 闭合误差回路；在常值/慢变外力下，`r` 指数收敛到真实外力。

连续时间核心方程：

```
ė = τ_ext - K·e,    r = K·e → τ_ext
```

离散实现只做“积分影子状态 + 比例反馈”，全程无比分。  
多维推广时，关键是把 `Cᵀ q̇` 与 `g(q)` 正确扣掉，其余与一维同构。
